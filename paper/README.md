# AdaptiveRAG IEEE Paper

This directory contains the final IEEE paper source files for the AdaptiveRAG project.

## Required Files
- `main.tex` (Main LaTeX source)
- `references.bib` (Bibliography database)
- `figures/` (Contains generated `.png` graphs)

## How to Compile
1. Create a new blank project on Overleaf.
2. Upload `main.tex`, `references.bib`, and the `figures/` directory into the project root.
3. Set the compiler to **pdfLaTeX** (default on Overleaf).
4. Compile the project.

## Final Output
The generated PDF can be downloaded from Overleaf. You may place the compiled PDF back into this directory later as `paper/AdaptiveRAG_IEEE_Paper.pdf` for reference.
